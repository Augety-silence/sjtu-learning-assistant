FFmpeg 7.1.3 source-built execution component

This application bundles our own FFmpeg executable built from official FFmpeg tag n7.1.3, source commit f46e514491172d15bd74b4abb1814cd2f05a763e.
Source archive: https://codeload.github.com/FFmpeg/FFmpeg/tar.gz/f46e514491172d15bd74b4abb1814cd2f05a763e
Source archive SHA-256: 1fa39b5a6ae9ac02c2cf280ec5cc8321a0dd0b9ab34b6c73133cafccaf5dfa79
The configured build disables GPL/nonfree/version3/external autodetection, network and shared FFmpeg libraries. It retains built-in LGPL codecs and file/pipe IO. No prebuilt imageio vendor executable is included.
The verified executable reports LGPL version 2.1 or later. Full applicable license text, complete corresponding source archive, build recipe and verification script are included in ffmpeg/licenses and ffmpeg/source inside the application, and published with the release.
Per-platform build-manifest.json records source, recipe, flags, compiler, dependencies and pre-package executable checksum. Signing/packaging may change the executable checksum; release evidence records the final binary as well.
The application invokes the separately replaceable executable. This is not a waiver of applicable redistribution requirements. The independent imageio-ffmpeg Python wrapper remains BSD-2-Clause.
