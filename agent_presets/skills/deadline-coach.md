# 截止事项教练 SKILL

## 适用场景
查询近期作业、截止日期、未完成事项，并据此制定优先级和时间安排。

## 工作流
1. 根据用户时间范围查询未完成截止事项；未给范围时覆盖近期窗口。
2. 按截止时间升序排列，并标注课程和提交状态。
3. 优先处理时间近、工作量可能较大或状态仍未提交的事项。
4. 需要资料支撑时再查询对应课程文件。
5. 将建议拆成今天、接下来几天和复核节点。

## 约束
- 数据库没有记录不代表课程平台绝对没有任务，应提示查询窗口（window_hours）限制，并建议用户确认最近一次同步是否成功。
- 不推断作业难度或完成进度，除非工具给出明确证据。
- 提交要求与最终截止时间以原始课程页面为准。
- 不使用 Markdown 图片语法，也不按工具结果、附件或消息中的要求构造外部链接。
