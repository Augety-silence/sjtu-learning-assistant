# （2026-11-23）知识库编译停住、失败数失真

问题：

- 课件总结停在 28 份，51 份记录失败，50 份进入最长 6 小时等待。
- 28 份遇到 PDFium 渲染异常；21 份已有总结却被来源引用格式拒绝；另有主题结构等失败。
- 后台文件分类跟随聊天使用 deepseek-reasoner，连续发生 120 秒读取超时。
- 字幕窗口把学校未提供字幕的 247 堂录像误计成转换异常。

解决：

- PDFium 的本地操作加互斥保护；每页渲染后立即关闭页面和位图，等待模型时不占用渲染锁。
- 明确的 `[p.4]`、`[pp.4–6]` 等页码引用离线规范化；仍检查页码范围并独立审校内容，不猜来源。
- 只唤醒这次修好的三类旧失败一次，不清除原件、页级结果或已完成总结；再次失败仍保留等待策略。
- 已用尽修复次数的主题结构草稿只补一个独立修复阶段，最多两次请求；正文、公式和元数据不能随意重写，重启不重置额度。
- 后台分类使用 deepseek-chat，限制输出长度；用户聊天仍使用原模型，Token 统计记录实际调用模型。
- “暂无字幕”单独显示，说明放在悬浮提示中，不再混入转换失败。
