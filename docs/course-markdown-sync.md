# 自动课件同步为 Markdown

## 已接入的实际流程

“知识库 → 课件自动同步为 Markdown”直接使用设置中的归档目录和 AI 连接，不需选目录、不需命令行。为避免旧用户无意发送真实资料，软件默认关闭；明确启用后持续运行。App 打开时补扫已下载课件，单文件/当学期下载和同步进程结束会唤醒；60 秒轮询也捕捉独立同步进程的新文件。App 退出暂停，重开继续，不安装额外系统守护进程。

只处理数据库登记为 active、downloaded，且真实文件安全位于归档根目录内的 PPTX/PDF/PPT；不扫描整台电脑、不下载新的 Canvas 资料、不读旧脏工作树。旧 PPT 不支持本地解析/整页渲染，会明确登记异常。PPTX 视觉渲染需要 LibreOffice；含宏、外部资源、嵌入对象或隐藏页的课件需安全导出 PDF。

## 对应关系与存储

原件 `学期/课程/分类/讲义.pptx` 对应 `Knowledge Markdown/Courses/学期/课程/分类/讲义.pptx.md`；保留扩展名避免 PDF/PPTX 同名覆盖。原件不改，独立知识库不会混入云盘 Archive 或旧学习笔记。

第一阶段为全部可解析文件提取全文，以 `source`、`source_type`、`source_sha256`、`converted_by` 和 `multimodal_status: pending` 前置元数据存储，按页组织。它不等于多模态完成：图像、图表和公式可能需要视觉复核。

第二阶段自动将逐页图文发送到已配置接口的 `qwen3.8-27b`，升级对应 MD，原始提取与 AI 解读分开保留。页图链接为经过 URL 编码的相对路径。版本和页级事务仍存于 `90_Inbox/Documents/<source-id>/<revision>`，旧版本保留。`99_System/Course-Sync.json` 记录自动镜像所有权、状态和每日额度，不含凭据。

## 额度、重试和笔记保护

- 默认每日 100 次页面调用，可在界面调整为 1—1000。失败/进程中断也记额度，重启不清零，跨午夜请求按新的日期计入。用完后自动等待次日；所有已成功解析的全文 MD 不受视觉额度限制。
- 每课件失败最多重试三次/日；其他文件继续。页级缓存和写前日志支持断点恢复。用户暂停只保存关闭开关，即使额度草稿无效也能停止；已发出的 HTTP 请求无法立刻撤回，但取消后不会提交其页面输出。
- 原件内容变更生成新版本，未修改的自动镜像会更新。人工修改、删除或未登记的同名 MD 不覆盖、不删除，界面标记异常；生成时再次检查所有权 hash。
- 切换主题/快捷键等无关设置不会中断编译。更改来源、AI 连接、同步开关或额度会取消旧任务，再按新配置执行。
