# SJTU Learning Assistant 1.8.12

本补丁版本发布此前完成的本地课程资料与知识库迭代，不替换或删除旧 Release。

## 课程和知识库

- 正常同步自动补齐学校仍允许访问的 available/completed 往期课程目录；已关闭或权限受限课程不绕过访问控制，异常保留缓存及续同步游标。
- 课程资料页顶部只保留搜索；课件与知识结果按原学期、课程及课时文件夹逐层浏览，移除重复入口和冗余说明，不删除原课件。
- 结果阅读区加宽，目录可收起；修复标签外框溢出和文件切换时的闪白、旧响应干扰。
- 阅读位置按文档 ID 与内容哈希独立记忆，切换前保存，回访恢复自己的位置；未读文档及内容更新后从头开始。记忆在本机保存，不承诺跨设备同步。

## 精炼总结与自动接入

- 每份正式总结的可见正文最多 2000 Unicode 字符（含标题、标点、公式和引用；检索元数据不计），目标为精炼课程主线、核心知识和适用条件，而非超长逐页讲稿。
- 全部页面的原文及视觉证据分批整理、独立审校并逐层合并；不能只读前几页、截断正文或省略输入主题。超长需重新压缩，来源审校未通过不发布。
- 已完成页稿和调用检查点可复用；编译契约升级保留旧正式稿及审校历史。人工修改和源文件哈希保护继续有效。
- 正式 Markdown 继续映射到原课件目录，可直接阅读、复制，供只读 AI/MCP 进行检索和完整读取；历史稿不作为重复检索结果。
- 自动与手动编译不设置 App 每日或单次总 API 调用额度；学校全局限速、取消、接口有限重试及单一坏文件隔离保留。已有 API 密钥只保存在系统凭据存储，不进入源码或发行包。

## 验证与边界

本地 macOS 完整 pytest 1152 通过、1 跳过、475 子测试；unittest 执行 1078 项、1 跳过。最终前端 62 文件／621 用例通过，Biome、类型检查、生产构建、compileall、许可证及秘密模式检查通过。Vite 主 chunk 超过 500 kB 的体积警告仍在；此前开发依赖审计的 3 项漏洞不以本次检查通过宣称消除。

32 页真实对偶课件使用官方交大 DeepSeek/Qwen 进行精炼和独立来源审校，最终字符数、覆盖、零调用续编及正式入库状态以交付记录为准。模型审校不替代教师验收，不声称全部课件已重编或每个数学结论已人工证明。

GitHub 七项 CI 与 macOS/Windows 发布工作流以本版本精确提交对应的 Actions 结果为准。Windows runner 测试、打包及结构检查不等于真实 Windows 界面、网络盘或原生拖拽验收。macOS 为 ad-hoc 签名，未经 Apple Developer ID 签名或公证；Windows 未提供商业代码签名。

用户已授权本次版本升级、本机部署、推送和发布一个新版本；旧学习资料、旧 Release 和所有回退副本均保留。
