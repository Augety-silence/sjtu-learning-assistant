# SJTU Learning Assistant 1.8.19

## 本次更新

- 新增持久化录播 ASR 队列：显式授权后扫描课程，只处理没有可用远程或缓存原文的录播，不因 AI 总结失败重复付费转写。
- 默认接口 https://api.siliconflow.cn/v1/audio/transcriptions；默认模型 XingChenAGI/XingChenASR-V3.2-Ultra。用户使用自己的独立 ASR Key；旧用户明确选择的模型和聊天设置保留。
- 提取纯音轨，超过服务时长或体积限制时按完整音频边界切分；响应先落盘，再验证并生成完整 Markdown。原始转写不套用总结的 5000 字符上限，不伪造精确字幕时间轴。
- 扫描、开始、暂停、恢复和显式有界重试；每段请求终身预算不因扫描、设置变化或重启归零。余额不足暂停，未知结果需要人工确认，不自动重复发送。
- 独立知识来源与阅读入口，标记为“MD完成/人工未校对”，不冒充已通过来源审校的总结。
- 退出前排空在途响应，固定在处理任务的输出目录，保护原件、检查点和人工修改。
- 补齐 Windows 跨进程锁、UTF-8 测试夹具及路径格式；移除产品与测试对个人恢复目录的依赖。
- 一并同步此前本地课件检查点恢复、公平调度和并行聊天修复；非课件过重教材保留原件，暂不编译，不清空资料或全库重编。

## 使用方式

设置 → 硅基流动 → 保存自己的 Key，核对模型和接口，再点击“开始批量转写”确认外发。MD 写入归档目录的 Knowledge Markdown/Recordings ASR/。普通关窗可后台运行；主动退出等待已发送响应落盘。批量默认关闭、暂停，不替新用户授权。

## 验证与发布边界

Mac 本地已验证零请求导入、人工稿保护、断点恢复及退出排空；公开测试使用临时合成夹具。实际 Windows 兼容结果以 GitHub CI 为准。源码版本更新不代表本机安装包版本已改变。

FFmpeg 包装库与执行文件许可证不同；供应商执行文件声明 GPL-2.0-or-later，精确对应源码和构建脚本仍须核验。CI 保留测试和构建，公开二进制产物及 Release 默认关闭。维护者只有确认分发条件后才能设置 FFMPEG_BINARY_REDISTRIBUTION_CLEARED=true。本次推送源码和创建 PR，不推送版本 tag 或发布未核验安装包。
