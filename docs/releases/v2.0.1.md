# 2.0.1 预览与自动更新

正式版本统一为 2.0.1。本机此前标记 2.0.2／2.0.3 的热修包含在此正式发行，已有 GitHub v2.0.0 标签保持不变。

- 修复已有 Markdown 的 Office 课件分流；真实 PPTX 可按页预览和搜索。
- 对经结构确认的 Office 容器使用 8,192 项成员上限，普通 ZIP 仍为 256 项；保留路径、压缩比、总量、XML 与宏防护。嵌入图表只跳过，不执行或加载。
- 修复归档说明图标的同行对齐，归档开关和 AI 个性化选项采用紧凑黑白灰控件，深色同步适配。
- 纳入文档、PDF 和在线观看字幕的关键词高亮、匹配切换与时间／页码定位。
- 安装版“检查更新”发现新版后自动下载官方 GitHub 安装包，验证精确大小与 SHA-256，再验证应用身份及隔离启动。暂停新模型请求，等待在途任务保存后退出；独立 helper 原子替换并重新启动，保留旧安装包，替换／重启命令失败时回退。
- 下载阶段支持取消，重复点击复用已有任务。缺少校验信息、平台包不匹配、网络异常或安装位置不可写时显示明确状态，不执行不完整安装包。
- Mac 使用官方 DMG；Windows 使用同版 portable ZIP 原子更新，保留已有卸载入口。Windows 版本资源同步 2.0.1；原生发行门禁继续覆盖 WebView2、FFmpeg、编码、启动与文件锁。

2.0.0 及更旧版本仅具备检查功能，需要先手动安装本次 2.0.1；从 2.0.1 起后续新版才能自动下载安装。自动更新只处理应用安装目录，学习资料、模型凭据、MCP 配置和日历保持原位。Windows Outlook 双向同步仍待 Graph 授权接入。

本机验收与 GitHub 双平台发行结果记录于产品路线图；发布状态以不可变 v2.0.1 Release 为准。
