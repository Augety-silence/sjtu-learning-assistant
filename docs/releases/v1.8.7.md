# SJTU Learning Assistant 1.8.7

本次补丁版本重构交大云盘文件工作区，并纳入两轮独立安全审计确认的传输、并发和路径边界修复。

## 更新内容

- 侧边栏“交大云盘”默认打开“我的文件”，原备份能力保留在“本地同步”页签。
- 新增空间用量、面包屑、目录浏览、搜索排序、分页、多选、上传下载、移动复制、回收站删除和传输列表。
- 上传文件只通过短时一次性能力凭证交给渲染层，前端不能直接读取本地绝对路径。
- 加固上传凭证并发消费、登记后文件替换、源文件截短、任务取消与缓存失效。
- 下载不覆盖已有目标或符号链接，并同步处理保存对话框期间的取消操作。
- 云端上传校验失败时不再冒险删除可能已被其他任务替换的对象。
- 修正 Windows 已打开文件锁定场景的跨平台回归测试。

## 验证与兼容

- 精确功能提交本地 Python 815 项通过、1 项跳过；前端 50 个测试文件、535 项通过。
- TypeScript、Biome、Vite production build、Python 编译、Python/npm 许可证、秘密模式扫描和差异检查通过。
- PR #44 的 Linux Python、Windows Python、前端、macOS App、Windows App、许可证与秘密扫描全部通过。
- Windows portable 与安装器由 Release workflow 在干净 Windows runner 构建并校验 SHA-256。
- 未使用真实学习数据或真实交大云盘执行上传、覆盖、删除及回收站恢复。
- Windows 打包版交互、2 GiB 实际传输和数千文件目录性能仍需真实环境验证。
- 存在导航前拦截等安全阻塞的 jAccount 登录补丁未纳入本版本。
