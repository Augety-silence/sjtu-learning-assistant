# SJTU Learning Assistant 1.8.6

本次补丁版本落地 2026-10-30 全模块夜审中已导出的可靠性、安全性、交互与跨平台修复，并纳入独立代码审查发现的补修。

## 更新内容

- 作业拖放改用短时、单次消费的随机能力凭证绑定原生层已验证路径，网页不能再自行登记任意本地文件。
- 原生拖放事件保持 AI 附件与作业文件两条链路兼容，并继续阻止文件拖入触发页面导航。
- AI 任务停止未确认时保留任务身份，恢复状态读取采用有限重试与退避，避免后台仍运行时丢失恢复入口。
- 删除当前 AI 会话后将焦点交回可见输入框，并修复知识编译覆盖确认与侧栏交互边界。
- Canvas 与交大云盘客户端支持凭据热更新；Canvas 代理错误、字幕时间解析、整理诊断与中文公式边界得到修复。
- 调试包与界面错误新增云存储临时凭据脱敏，并兼容 Windows 网络盘或重定向 AppData 下的 SQLite URI。

## 验证与兼容

- 本地完整回归：pytest 843 项通过、1 项跳过，另有 324 个子测试通过。
- 前端 49 个测试文件、516 项通过；Biome、TypeScript 与 Vite production build 通过。
- GitHub CI 的 Linux Python、Windows Python、前端、macOS App、Windows App、许可证与秘密扫描全部通过。
- macOS 本地应用从合并后的精确 main 提交构建、签名并部署，原 v1.8.5 bundle 保留回退副本。
- Windows portable 与安装器由 Release workflow 在干净 Windows runner 构建并校验 SHA-256；Windows 网络盘和拖放交互仍需真机回归。
- 未使用真实学习数据执行提交、上传或删除，也未调用付费模型。
