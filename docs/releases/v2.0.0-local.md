# 2.0.0 全界面迁移与本机部署

以公开 main c954db025cdd56038d0216569919c17e79b1a280（1.8.28）为基线，继续隔离分支 aime/1795796000-ui-2-0-local。用户此前否定仅迁公共壳和 AI 的部分版，本轮按原审阅 HTML 重建所有页面结构与独立 CSS。代码仍是 React + TypeScript，宿主仍是 Python / pywebview，生产使用原真实接口，示例只在独立验收入口。

## 界面与功能

- 新 V2Shell、统一 SJTU 品牌、固定 248px 侧栏；1200px 以下224px。Logo 在工作台和 AI 都是 x24/y24、36×36；72px 顶栏。旧第一方 CSS 只作用于 classic，新2.0样式独立生效。
- 概览：连续三摘要和最近截止／最新消息／今日日程三列；真实作业和消息深链，日程独立滚动与 AI 整理入口。
- 日程：月度缩略、周日历、今日／本周切换；详情、个人日程创建编辑删除、ICS导入、Canvas作业跳转。个人日程本轮存学习助手本机浏览器存储，没有接Apple Calendar。
- 作业：紧凑列表与详情、文本/URL/本地或云盘文件提交；保留草稿、原提交确认与服务端回读。
- 消息：邮件、Canvas公告和Canvas作业三种来源，原分页搜索、已读、正文和附件；整块选中。未新增邮件发送功能。
- 课程资料：全部学期目录、文件多选下载、状态和修改时间、预览、本地打开／Finder定位、原移动归档恢复控制器。缓存容量仅统计索引内已下载文件，不声称读取整个硬盘容量。
- 视频：16:9播放器；PPT、字幕、时间轴和学习工具均在框内浮现，PPT双击切换主视角；保留原快进、全屏、播放进度和字幕控制器。
- 交大云盘：我的文件／本地同步，复选框、批量下载、修改时间、目录／文件详情；原传输队列、冲突确认和备份逻辑保留。
- 知识库：编译产物目录和阅读、真实状态队列、编译设置和安全停止；未伪造成功或失败降级。
- 设置：按分类显示，表单保持挂载以保存草稿；浅色、深色和Aime绿点缀具备实际主题效果。
- AI：单行助理选择、悬浮模型／推理菜单；内/外技能来源bar及中央配置、工作区、MCP和全部任务搜索；输入输出共同宽度，附件在输入上方，紧凑字数栏。原会话、流式回答、工具轨迹、文件变更提议与确认继续接真实接口。
- 教师／助教成绩管理、花名册和批改入口及桥接动作已移除；保留学生自身作业分数和提交结果。
