# 2.0.0 夜间最终调整

本批继续采用 React + TypeScript 与独立 2.0 样式，保留真实控制器、桌面 Bridge 和数据接口。示例只存在于隔离视觉／测试入口。

## AI 工具与本地文件

综合助理注册学习、文件与日历工具后，超过旧版请求校验的 16 个定义上限，导致请求在本地被拒绝。同步与流式请求改为共享 64 个定义上限；原 JSON 大小、结构、工具白名单及目录边界仍执行。

桌面 Agent 和独立 stdio MCP 共用用户选择的 `ai_workspace.json`。未选择、失效、空白或损坏的工作区不会注册文件工具。支持已选目录的浏览、文档读取和文件变更提议；模型不直接应用提议，用户确认后才写入。外部 MCP 更换工作区后需重启连接，重新载入配置。原路径越界、隐藏项、符号链接与应用／课程归档目录保护继续生效。

输入框按原型恢复左侧添加／助理与右侧模型／推理／停止／发送分组。添加菜单连接真实本地附件选择器，以及中央工作区、技能、MCP 配置入口。框外为工作区、修改前确认入口及字数。正文、输入与输出宽度保持一致；控件使用紧凑字号。

## 日程

检查本机飞书安装资源和窗口后，以用户提供的日历截图作为布局依据：辅助功能没有暴露内部日历控件，也未提取到日历 React 源码。

移除最右今日／本周列表，保留左月缩略与主日历。右上切换日／周／月；日期表头、独立全天带固定，00:00–24:00 半小时网格局部滚动，左栏不随时间轴移动。点击所在格创建，默认长度 30 分钟；跨午夜结束日期、全天结束边界、跨日显示、事件详情和作业跳转继续由真实逻辑处理。

已结束事项标灰，当前时间线和结束状态每分钟更新。宽周与日视图的重叠事件并排；1050px 以下周视图使用时间冲突组，显示数量与完整时间范围，点击切换对应日视图。月视图采用有界六行布局，日期中的长内容独立滚动。
