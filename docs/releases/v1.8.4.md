# SJTU Learning Assistant 1.8.4

本次补丁版本合入作业文件拖拽修复，以及 2026-10-27 全模块夜审中已导出的可靠性、安全性与可访问性改进。

## 更新内容

- 作业文件区支持 macOS/Windows 桌面拖拽，修复原生拖放事件时序、在途登记覆盖与旧回退提示干扰。
- Canvas 附件名称优先使用 `display_name`，安全解码网址转义名，中文文件名不再显示乱码。
- 修复 AI 后台任务转交时误取消、恢复后消息重复及设置控件保存时焦点丢失。
- 改进长文件名预览、代码块区域和表格键盘可访问性。
- 修复知识编译首次持久化失败后的假运行状态、IMAP 连接中断误分类和 Windows 控制台编码异常。
- 优化诊断与云归档脱敏正则的最坏情况性能，避免长输入卡顿。
- 云盘客户端安全处理超长 `Retry-After`，恢复对话框不再为不可恢复对象追加误导提示。
- Pillow 运行时约束更新至 13.x，并继续执行许可证与秘密扫描。

## 验证与兼容

- 本地完整回归：Python 830 项通过、1 项跳过、324 个子测试通过；前端 49 个测试文件、506 项通过。
- 审查补修定向回归：Python 14 项、前端 15 项通过；Biome、TypeScript 与 Vite production build 通过。
- Python/npm 许可证检查、秘密扫描和关键模块编译通过。
- 未使用真实学习数据执行提交、上传或删除，也未调用付费模型。
- Windows 构建与内嵌 manifest 由 GitHub 干净 runner 验证；不等同于 Windows 10/11 真机拖拽验收。
