# SJTU Learning Assistant 1.8.0

本次功能更新重构了 AI 学习工作区，加入图片多模态对话与原生文件拖拽，并完成界面精简和冗余代码审计。

## 更新内容

### AI 学习工作区

- AI 对话直接集成到侧栏，无需先进入独立“AI 助手”页面。
- 优化对话布局、输入区、执行状态与活动面板，移除输入框旁异常矩形背景。
- 支持图片附件与 Qwen 3.8 图片识别，按照上海交通大学模型平台的兼容格式发送请求。
- 合并 system 提示并对图片请求使用兼容的非流式模式，修复上游 400 参数错误。

### 文件与拖拽

- 支持从 Finder 直接拖入图片和其他附件，松手后立即生成附件卡片。
- macOS 通过 WKWebView 原生拖放接口读取 Finder 文件 URL，不再降级为文件选择器。
- 保留附件数量、文件类型、大小、受控副本与路径安全校验。

### 质量与稳定性

- 清理审计发现的冗余实现，并补充桌面桥、附件、多模态消息与 UI 回归测试。
- 修复 macOS 透明窗口下输入区域的非透明背景伪影。
- 完成真实交大 API 图片问答、本地 macOS 打包、签名和 Finder 拖拽验收。

## 验证与兼容

本次更新通过 726 项 Python 测试、302 个子测试、465 项前端测试、Biome、TypeScript/Vite 生产构建和 macOS 签名校验。正常覆盖安装不会删除现有应用数据、已归档资料或系统凭据。
