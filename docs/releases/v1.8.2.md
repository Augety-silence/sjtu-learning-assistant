# SJTU Learning Assistant 1.8.2

本次补丁版本集中落地 2026-10-22 至 2026-10-24 审阅确认的可靠性修复，重点覆盖云盘归档、恢复、敏感信息保护、并发任务状态和桌面端交互一致性。

## 更新内容

### 云盘归档与恢复

- 修复 Canvas 同目录文件互换名称时可能误删对方新下载文件的问题，旧路径仅在大小与 SHA-256 都能证明归属时清理。
- 上传确认后的大小核对失败会清理云端残留对象，避免后续重试持续被“拒绝覆盖”阻断。
- \`needs_verification\` 任务通过重新下载与 SHA-256 强校验确定终态，不再仅依赖远端元数据。
- 覆盖恢复增加二次确认、隐藏快照、失败自动回滚和成功后快照清理；重试仍需重新确认。
- GET、流式下载与已签名幂等 PUT 对 429/500/502/503/504、超时和网络错误执行最多三次的有限重试，并限制 \`Retry-After\`；普通写 API 不自动重放。
- 分片上传只在签名认证失败时续签，其他远端错误保持原始失败原因。

### 隐私、并发与任务反馈

- 补齐 JSON 引号键、URL 编码等号和 \`Authorization: Basic\` 等敏感字段脱敏。
- 认领语句自身因 SQLite busy 等原因失败时，不再误把其他调用正在上传的任务标记为失败。
- 并发重试返回明确的 \`in_progress\` 状态，前端不再把所有重试都提示为“失败任务已重新执行”。
- 修复消息快捷键异步状态竞态、操作后焦点丢失及多处页面错误提示、状态恢复和可访问性问题。

### 发布可靠性

- 预发布标签会自动标记为 prerelease 且不会覆盖 Latest；正式 \`v1.8.2\` 仍发布为 Latest。
- 延续 macOS DMG、Windows portable、Windows 安装器及各自 SHA-256 文件的统一发布流程。

- 前端：48 个测试文件、465 项测试全部通过。
