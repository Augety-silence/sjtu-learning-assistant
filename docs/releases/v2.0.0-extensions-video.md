# 2.0.0 视频与扩展更新

本批继续使用 React + TypeScript、真实桌面 Bridge 和独立 2.0 CSS，示例仅在测试夹具。

- 视频左侧录像列表、右侧 16:9；真实播放控制、倍速、音量、全屏、字幕时间标签与学习工具均在框内。PPT 可拖动缩放，双击和主视角互换。
- 仅综合助手与资料库助手；历史专项助手兼容映射至综合助手，原专项提示转为内置技能。
- 技能配置内置/外部分栏；外部 ZIP 识别原始 SKILL.md、YAML、README、scripts、资源目录。启用开关与脚本权限独立；对话支持最多8个启用技能、多选附件，不改用户输入正文。
- 标准 mcpServers JSON 支持粘贴、文件导入与 DuckDuckGo 模板；连接发现、服务开关、逐工具权限及测试搜索均使用真实后端。
- 资料库助手仅使用本机课程、编译库与附件读取工具，禁用外部 MCP、日历和脚本/工作区写入；模型 API 仍按用户模型配置通信。
- 作业提交禁用、正常、悬浮状态保留文字；按钮采用黑白灰，正文说明深色，选中加粗。

使用：AI 助手左栏「技能配置 → 外部技能 → 导入 ZIP」；选择技能在输入工具栏，显示在输入框上方。脚本默认关闭，启用后由本机进程执行。MCP 左栏「MCP 服务 → 添加/导入」可使用 DuckDuckGo 模板；需要本机 uvx。
