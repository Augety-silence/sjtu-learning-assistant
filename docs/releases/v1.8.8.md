# SJTU Learning Assistant v1.8.8

本版本整合此前本地多模态学习助手功能和 2026-11-13 全模块夜审中经当前代码复核成立的修复，不覆盖用户资料或旧工作树。

## 学习助手改进

- AI 可读取课程课件和文档文本，并向受支持的视觉模型发送受控的内嵌图片。
- 对话提供每轮真实执行详情，修正计时与上下文预算，改善长回答、长会话历史、流式输出和失败恢复。
- 支持用户自定义 skills 和审批门控的文件工作区；文件访问和写操作继续遵守明确授权与路径边界。
- AI 结果落库在可恢复事务冲突时有限重试，不重复调用模型；保留会话时间、附件和工作区上下文。

## 稳定性与安全

- 改善窗口初始隐藏、失败恢复、后台任务状态探测、同步失败解锁以及取消后的课程状态回读。
- 完善日志和嵌套凭据脱敏、设置损坏的安全降级、字幕时间与控制字符解析、受控深层 JSON 处理。
- 加固更新和转写的输入、哈希、容器校验及桌面打包资源检查。
- 修复跳转焦点导致的路由/草稿干扰，并补齐旧 WebKit 能力降级及样式变量。
- 保留既有云盘根目录保护、待对账状态、原生拖拽可信路径和会话隔离安全契约。

## 验证基线

功能修复提交 `085bb3c` 的本地完整验证：Python unittest 882 项执行（881 通过、1 跳过）；pytest 956 通过、1 跳过、368 子测试通过；Vitest 56 文件、565 用例通过。Biome、TypeScript/Vite 生产构建、compileall、Python/npm 许可证、项目秘密模式和 diff 检查通过。发布版本另经过七项 GitHub CI 与 macOS/Windows 发布工作流，最终运行结果和资产以对应 Actions 与 Release 页面为准。

macOS 原生烟测使用隔离空资料和系统级网络阻断，未连接真实学习资料或付费模型。运行成功不等同于全部业务端到端验收。

## 安装与边界

正式资产为 Apple Silicon macOS DMG、Windows x64 安装器和免安装 ZIP，均附 SHA-256 文件。macOS 使用 ad-hoc 签名但未经 Apple 公证；Windows 未提供商业代码签名，首次运行可能出现系统安全提示。请仅从项目 Release 下载。

尚需真实环境验证：Windows 原生拖拽、网络盘/映射盘及重定向 AppData；macOS/Windows 真实交大云盘登录；专用合成资料测试空间中的上传、覆盖、删除、回收站恢复及大目录性能。没有使用真实学习数据执行写入测试或调用付费模型。

夜审仍有未完成单元和需要跨模块设计的历史观察；本版本不宣称 M1–M9 全部历史问题清零。旧 Release 和本地回退副本保留，后续按独立验收单元继续推进。
