# SJTU Learning Assistant 1.8.5

本次补丁版本落地 2026-10-29 全模块夜审中已导出的可靠性、安全性、交互与跨平台修复，并纳入独立代码审查发现的补修。

## 更新内容

- 修复评分对象校验、作业与 AI 文件拖放时序、页面切换后的异步状态覆盖，以及 SSE 流式响应解析边界。
- 完善转写诊断、重试与后台 worker 首次错误日志，短启动环境也不会误吞首条故障记录。
- 修复 Canvas 离线错误语义、数据库事务边界和 AI 分类输入约束。
- 云归档校验中断后可安全回到待校验状态，批量归档不再重复下载仅云端文件。
- 扩展云存储临时凭据脱敏范围，结构化字段与长文本仍保持安全、线性处理。
- 修复 Windows 只读文件覆盖恢复后的临时副本清理，并增强恢复与归档路径的异常处理。
- 改进设置、应用壳层和 AI 对话交互的一致性与可访问性。

## 验证与兼容

- 本地完整回归：pytest 841 项通过、1 项跳过，另有 324 个子测试通过；unittest 771 项通过、1 项跳过。
- 前端 49 个测试文件、511 项通过；Biome、TypeScript 与 Vite production build 通过。
- GitHub CI 的 Linux Python、Windows Python、macOS App、Windows App、许可证与秘密扫描全部通过。
- macOS 本地应用从合并后的精确 main 提交构建、签名并部署，原 bundle 保留回退副本。
- Windows portable 与安装器由 Release workflow 在干净 Windows runner 构建并校验 SHA-256。
- 未使用真实学习数据执行提交、上传或删除，也未调用付费模型。
