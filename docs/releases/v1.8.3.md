# SJTU Learning Assistant 1.8.3

本次补丁版本落地 2026-10-24 全模块审计确认的可靠性与安全修复，覆盖应用壳层、视频学习、AI 对话、课程数据同步及桌面端打包。

## 更新内容

- 修复 ffmpeg 自动探测播放列表时可能读取非视频本地路径的问题；现在先校验视频容器魔数并限制 demuxer。
- 修复大体积 PDF 预览在 UI 主线程同步解码导致卡顿的问题，改为可取消的异步 Blob 加载。
- Canvas 提交成功但回读失败时保留 `submitted` 审计状态，不再误记为失败。
- Windows 构建保留 PyInstaller 默认兼容性 manifest，并在 CI 中强制校验 EXE 内嵌 `longPathAware=true`。
- 合入 9 个模块共 18 个不重复的审计补丁，增强焦点恢复、并发任务、文件处理、状态反馈与错误边界。

- 本地完整回归：Python 688 项通过、1 项跳过；前端 470 项通过；最终修复定向回归 Python 30 项、前端 19 项通过。
