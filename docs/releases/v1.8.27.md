# SJTU Learning Assistant v1.8.27

完整功能版：Mac Apple Silicon DMG、Windows 10/11 x64 安装器 EXE、Windows 便携 ZIP。
不是此前仅显示合成数据的启动测试包，正常版本使用用户本人配置的账户和既有桌面桥接。

## 主要改进
- 修复 Windows 恢复流程的原生跨进程文件锁与目录同步兼容性，仍强制文件 flush/fsync、不可变响应哈希、只读封存与原有预算约束。
- 取消/即时补充的请求线程读取增加有界检查，保留原读超时与 1.5 秒回归断言；在连接复用前恢复请求专属读取回调，避免影响其他请求，保留已收到付费内容与 usage。
- 修正中文 UTF-8 测试夹具及 Windows 生命周期测试隔离，不跳过失败子集、不省略原生启动与发行校验。

- 修复取消/即时补充时的跨线程 socket 关闭竞态：观察线程仅 shutdown，中断后的释放由请求线程完成；保持原有1.5秒回归预算、模型限额与已付费响应保护。

- Windows 使用 WebView2 本地资源映射，补齐首页与直接资源预检、导航错误提示，避免只检查磁盘存在性就判定启动成功。
- 保留本地最新版的 Aime 风格与工具调用归组、函数/参数/具体结果预览、原有模型/权限/草稿/停止待确认边界。
- 保留当前学期资料目录、基础 Markdown 队列、知识编译检查点、课堂总结与云盘版本/断点续传修复。
- 原有跟随系统、浅色、深色模式和用户配置仍受支持，不携带任何预置账号、密钥或学习资料。

## 安装与升级
- Mac：选择 macOS-arm64.dmg；仅提供 Apple Silicon 安装包，Intel Mac 不适用。
- Windows：推荐 Windows-x64-Setup.exe；安装器包含完整前端和运行时。需 Microsoft Edge WebView2 Runtime。
- 便携版：完整解压 portable.zip 后运行其中的 EXE，不能单独移动 EXE 或直接从 ZIP 内运行。
- 现有用户数据、人工稿与付费检查点不随安装包清空；不全库重编，不自动替用户提交作业或发布评分。
- ASR 外发、文件写入及恢复仍需在原页面明确确认。

## 发行校验
公开 Release 附件仅 DMG、EXE、ZIP 三个文件。校验和、原生执行证据、FFmpeg 源码/许可证核验通过构建内部产物验证，不作为额外附件上传。
Mac 与 Windows 必须从同一不可变源码提交构建，并运行实际安装包前端启动门禁后才允许发布；原生校验最终结果与源码身份由发行流程追加记录。
FFmpeg 对应源码与许可证随程序包内附带，保留原有许可证和安全校验。

## 发行状态与边界
v1.8.25、v1.8.26 的既有标签保持不变，失败草稿不公开。v1.8.27 为向前修复版本；只有同一不可变提交的双平台全量测试、实际安装包前端启动与三附件来源/哈希校验全部通过，发行流程才转为公开。本机回归与模拟编码/锁测试不能替代 Windows 原生验收。没有替换本机已安装 App，没有操作真实学习原件或发起新增模型请求。
