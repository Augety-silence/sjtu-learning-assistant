# SJTU Learning Assistant 1.7.3

本次是视频 AI 整理与恢复流程的可靠性补丁，包含正式版 1.7.0 之后已合并的改进。

## 更新内容

- 播放录像时自动准备学习材料，按分段显示可用内容，并随播放位置更新；保留时间戳跳播、倍速与切换录像的同步保护。
- 自动恢复只重跑尚未完成的技术阶段，复用有效分块；处理已结束但内容待核对时，不再反复自动校对。
- 区分“处理已结束待核对”“等待自动恢复”“自动恢复已用尽”和“已取消”，仅在确有待执行恢复时显示恢复时间。
- 收紧讲义修复：只有能够证明错误的来源标签允许调整；题面、答案、主题、证据、题数与顺序受到保护。不可信或存在其他结构错误的基线停止修复，保留错误提示。
- 加强取消持久化、恢复任务去重及输入、课程记忆、模型与端点的缓存绑定；应用意外退出后的中断任务需要显式重试。
- 修复带工具的 Agent 流式响应与非流式降级，保留失败任务草稿及可恢复错误的重试入口。
- 修复 Windows 更新检查同时匹配安装器和便携包的问题：默认选择安装器，显式选择便携包仍受支持，并继续校验下载来源与 SHA-256。

## 验证与兼容

本次改动经过独立审阅，补充了真实后台线程跨桥接处理/取消、课程记忆版本变化、来源修复保护等合成回归。发布所用源码、CI 与构建结果由对应 tag 和 Actions 记录追溯。

提供 macOS Apple Silicon（arm64）DMG，以及 Windows x64 portable ZIP 和安装器；各包附 SHA-256。正常覆盖更新不会主动删除应用数据和系统凭据。建议更新前退出旧应用，并保留旧包以便回退。

## 已知边界

- AI 输出仍需人工核对。此前真实模型验收出现过结构校验失败和部分材料；本次不宣称所有模型调用或内容质量均已通过。遇到失败时保留原始/已有材料，并显示恢复或人工重试状态。
- 取消会阻止后续处理；已发出的字幕或模型请求可能需要等待有界请求返回，不能保证立即撤销远端请求。
- macOS 公共构建未使用 Developer ID 签名或公证；本地个人开发签名不等于面向所有用户的签名认证。Windows 构建已纳入 CI，未声称在本机完成 Windows 原生运行验收。
