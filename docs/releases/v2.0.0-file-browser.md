# 2.0.0 文件浏览与悬浮预览更新

课程资料与课程知识库采用目录／文件两栏。左侧只保留目录，右侧显示当前目录直属文件及下一层文件夹；通过路径导航返回上级。知识库浏览先在服务端筛选直属文件，再分页，避免客户端过滤当前页造成漏项；关键词搜索继续检索选定范围内的全部后代文档。原课程身份、学期隔离及文档 ID 保持原契约。

点击文件或聚焦后按空格打开独立预览窗口，关闭按钮、遮罩和 Escape 均可关闭，并返回原文件焦点及列表位置。正文只在窗口内滚动。预览加载状态留在窗口内，不再叠出成功提示条；失败仍提示错误，并可重试。资料批量下载、文件夹定位、本地打开、拖放归档、手动分类与恢复自动分类继续调用原接口。

Markdown 使用已有安全渲染；知识库保留 GFM 表格、数学公式、从头阅读、超长文档分页与阅读位置记忆。关闭时保存阅读位置并使旧读取请求失效，晚到响应不能重新打开窗口。PDF 复用现有 Blob 预览源，铺满阅读区并在关闭时释放资源。PPTX、DOCX 沿用原有结构化内容预览，呈现页码／正文；需要原版排版时使用“本地打开”。这次没有新增 Office 原版排版渲染器。

云盘选中操作替换固定顶部工具栏内的常规操作，不再插入新的行。搜索框、表头、列表与滚动位置在选中、取消、多选、下载及传输浮层切换时保持稳定；窄窗口使用带名称提示的图标操作。传输入口仍与个人空间并列，完成下载不会自动弹出窗口。

工程继续使用 React + TypeScript，示例数据仅位于独立验收夹具。`direct_children` 是新增的可选只读搜索参数，默认关闭；原经典模式与 AI/MCP 搜索保留原范围。新版预览通过 `FloatingDocumentPreview` 复用焦点锁定，资料预览通过 `FilePreviewContent` 复用原预览器，知识正文通过 `KnowledgeDocumentReader` 复用阅读逻辑。

验证包含相关前端 78 项、知识库后端与目录身份 35 项。Mac 完整构建前端 679 项、后端 1561 项通过（1 项平台条件跳过）；最后的 PDF 高度与提示条修正另做针对性回归及纯前端重建、签名验包。1000／1440 两种原生 WKWebView 窗口检查通过，覆盖 Markdown、PDF、PPTX、DOCX、空格打开、关闭焦点、列表位置、知识库阅读位置、目录导航及分页。最终夹具也重新验证云盘勾选过程。

真实本机 DesktopBridge 已验证本地知识库目录与正文读取：316 份文档、4 个来源，直属目录筛选正确。读取 8000 字符仅用于检验，没有导出正文或修改课程文件；文件定位桥接检查没有实际打开 Finder。
