# SJTU Learning Assistant 1.8.1

本次补丁版本固化 1.8 系列的本地部署与正式发布结果，确保 macOS 应用使用当前前端资源和原生 Finder 拖拽实现。

## 更新内容

### 本地部署一致性

- 将正式版本推进至 1.8.1，避免旧 1.7.4 本地构建与最新源码混用。
- 重新构建并核验 macOS 应用，确认应用包内版本、前端资源与仓库源码一致。
- 保留原生 WKWebView Finder 拖拽链路，不以回形针文件选择作为降级方案。

### 发布物核验

- 校验 macOS DMG 的 SHA-256、应用签名与 bundle 完整性。
- 确认正式包不再包含旧 WebView 文件路径降级提示。
- 延续 Windows portable、Windows 安装器、macOS DMG 及对应 SHA-256 文件的统一发布流程。

## 验证与兼容

- 前端：48 个测试文件、465 项测试通过。
- Python：678 项测试通过。
- macOS：应用签名、bundle 校验、DMG SHA-256 校验通过。
- GitHub Release：macOS 与 Windows 发布任务继续由标签工作流自动构建和校验。
