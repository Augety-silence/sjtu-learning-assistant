# SJTU Learning Assistant 1.7.4

本次更新合并了 2026-10-20 全仓审阅修复，并统一了应用内选中状态的滑动指示器。

## 更新内容

### 稳定性与数据安全

- SQLite 损坏隔离后保留恢复标记，快照暂时不可用时不会把数据库误判为全新安装。
- 备份删除本地文件前增加内容摘要核验；恢复任务运行中拒绝覆盖计划，避免丢失占位文件与恢复目标。
- 云归档搜索、分页状态和目录重新选择行为修正；本地归档盘暂时离线时应用仍可启动。
- Canvas 文件确认链安全处理同源重定向，并保留认证、限流和权限错误分类。

### 学习、AI 与同步

- 强化课程学习编排、转写管线、媒体处理、知识编译和 AI Agent 工具边界及错误恢复。
- 知识编译只使用本轮有效 Lecture，避免已删除或改名资料残留进入概念与证据链。
- 修正课程资料、消息、日程、作业和邮件同步中的分页、去重、时区及状态一致性问题。
- 草稿页同步与归档完成后延迟刷新，离开草稿页时自动补刷新，避免未提交内容丢失。

### 界面与无障碍

- Toast 改为模态层豁免的 Portal，弹窗打开时仍可播报、悬停和关闭；提交错误保留单一就地播报。
- 补充键盘焦点、文本对比度、Windows 字体回退与降低透明度模式下的不透明表面。
- 侧栏当前页高亮改为共享矩形，在主导航和设置之间保持连续移动。
- 日程、消息、作业、视频、字幕结果等标签页使用统一的滑动选中指示器。
- AI 偏好、主题选择、视频整理状态和知识编译阶段共享一致的选中反馈。
- 弹簧回弹统一为 `bounce: 0.04`；持续时间按实时移动距离在 0.12–0.28 秒内计算，相邻切换更轻快，远距离移动更易跟随。
- 保留未显式启用指示器的标签页原有外观，避免扩大视觉变更范围。
- 遵循系统减少动态效果设置；键盘语义、焦点与原有业务行为保持不变。

## 验证与兼容

本次更新通过 Python pytest/unittest、Biome、TypeScript/Vite 构建、前端全量组件测试、许可证检查、秘密扫描和 macOS 应用包验证。macOS 应用版本随本次更新提升为 1.7.4。

正常覆盖安装不会主动删除应用数据和系统凭据。建议更新前退出旧应用。
