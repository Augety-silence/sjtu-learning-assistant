# 2.0.3：Tavily 授权与联网会话修复

本机已安装 2.0.3，修复 Tavily 已授权却被提示“没有可用网页检索工具”的问题。

## 原因与修改

本机 Tavily 服务已启用，权限为 `all`，五个工具均已勾选，但服务没有声明 `readOnlyHint`，因此工具的 `read_only` 元数据为 false。原网页工具筛选额外要求 `read_only`，忽略用户显式选择的全部授权，导致在线会话工具列表为空，并在模型调用前结束。

- 注册、网页筛选和实际调用共用权限判断。缺少只读声明时，仍需用户显式全部授权；没有自动提升权限。
- 补充 Tavily extract/crawl/map 和 Exa/Jina 的网页工具识别。
- 支持 Tavily JSON `results` 与 stdio 的 Title/URL/Content 格式，按实际条目显示数量。
- 识别额度、认证与限流业务错误，避免 MCP 外层 `isError=false` 时被计为成功。
- 提示模型附实际 URL；模型遗漏时补充本轮检索链接。查询对象切换后清除旧对象的链接。
- 真机检索验收支持指定服务，保持服务权限与工具选择，并使用独立数据库快照和合成隐私标记。

## 验证

相关回归 121 项及后续针对回归 41 项均通过；覆盖工具启用、取消勾选、降权、已有会话撤权、在线来源隔离、真实条目计数、业务错误和补充指令后的来源切换。

macOS 新包通过签名、资源、FFmpeg、打包 MCP 与真实前端启动检查。可回退安装后，二进制与构建一致，76 个前端资源核对一致，70,006 个学习文件核对零变化。原 MCP 配置字节保持一致，后台 AI 恢复原启用状态。

安装后的应用使用真实 deepseek-chat、综合助手和用户已有 Tavily 配置，对“魏煊是谁”执行搜索：26.73 秒、2 次模型请求、1 次 Tavily 搜索、5 条结果；回复包含可点击来源，未调用本地资料工具，未触发自动续写。

首轮候选包虽然成功调用 Tavily，但只显示一项且回复未附 URL，因此没有作为最终交付验收；修正解析和链接后完成上述安装验收。

## 边界

本次验证证明授权与工具链路可用，不代表全部搜索结果或人物身份已核验。搜索摘要不能替代原文核对。此次未修改模型、密钥或服务权限；未公开发布 GitHub 版本，Windows 未进行安装实测。
