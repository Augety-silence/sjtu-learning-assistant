# 2.0.0 联网调用与视频修复

本批保持 React + TypeScript 与真实桌面接口。用户反馈的联网失败确认为 DuckDuckGo 上游未返回可验证结果，MCP 协议正常，不能把该响应记录成成功检索。

## 联网调用

- 上游“无结果／可能触发 bot detection”响应标记为执行失败，工具轨迹不再显示成功。不可重试的失败禁止同轮反复改词。
- 新增标准 stdio MCP 的 Bing RSS 搜索服务，来源明确，返回真实 URL、标题与摘要，只读工具。配置模板由桌面端给出本机可执行路径，无新增依赖。
- 本机备份原 MCP 配置后添加 Bing；关闭受限的 DuckDuckGo search，保留其已授权网页读取。综合助手按需使用，资料库助手不能调用。
- 纯联网请求不再自动预取本地 Wiki 目录。RSS 空结果与网络／格式失败区分，不编造搜索结果。

## 视频与字幕

- 可见录像标题、播放标识和卡片主体统一接入播放热区，保留更多菜单的独立操作。
- 主框固定 16:9，控制、字幕和学习面板在播放器内部。
- 字幕默认出现并跟随媒体时间。最长段正文完整保留，限制两行高度，通过局部滚动查看；不虚构逐句时间。
- 字幕列表的时间标签跳转到原 VTT 起点，标识当前段并在列表内部滚动。切换课程重置为字幕标签。
- 原始字幕详情也位于播放器内，使用相同解析与定位逻辑；保留 Markdown 原文资料的阅读格式。

## 验证边界

隔离测试使用独立示例数据；真实录像验证使用现有授权流，仅在 Mac 保存签名地址，不导出原始链接或字幕。完整结果见本目录配套 JSON。未复测日历授权，不将此批视频和联网检查作为日历验收。

最终本机验收：669项前端、1557项后端（1项跳过）、Lint、许可与凭据扫描通过。真实DeepSeek综合助手执行1次Bing MCP调用（16.04秒）返回交大官网。真实录像主框16:9、1920×1080、86段字幕，4次代表段跳转均匹配且高度54px；1000/1440原生窗口检查通过。75项安装资源及二进制一致；69,590保护文件零变化，AI已恢复。
