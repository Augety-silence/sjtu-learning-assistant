# 精炼课件总结与独立阅读进度

默认 PDF/PPT 多模态输出为 `course-summary-v1`：整份可见正文（含标题、Markdown、公式与引用）最多 3000 Unicode 字符，不包括检索用 YAML 元数据。按去除空白／提取页码后的原始文字约30%给出编辑目标，目标在160–2600字符内；短课件不凑字数，重要主题、公式与条件优先于机械比例。Markdown正文上限2850字符，为标题留空间。课堂总结同样使用3000字符上限，原始字幕不裁剪，Wiki接收完整新总结。

结构修复仍超长或缺页时，最多再进行两次有缓存的定向重组：根据实际缺页证据补齐实质主题，合并重复观点，不能只回填页码或截断正文。原文、视觉复核及篇幅目标均绑定缓存身份；成功后仍须独立来源审校。

课程总结按主线、核心知识、适用条件与易错点组织，不自动追加长证明、题库、逐页复述或重复附录。全部来源页仍逐一处理，原文与视觉证据分批提供并由 Qwen 来源审校；多批总结逐层合并，必须保留所有输入主题标识与页面范围。摘要有意不展开重复例题和细节，不代表完整教材替代品。

逐页原文与页图仍在对应 `90_Inbox/Documents/.../pages` 和 `assets` 目录，可通过定位结果目录查看。升级前的完整讲义和审校记录保存在对应 `history` 目录，不作为新的检索结果重复展示。已有人工修改或丢失的生成文件仍以哈希保护，自动更新暂停，不覆盖原件和人工笔记。

阅读器由三栏改为目录/文件收纳侧栏＋宽正文区，目录可收起，窄容器纵向排列。阅读进度在本机存储，仅包含文档 ID、内容哈希、分页起点与滚动位置，不存正文或 API Key：

- 切到新文件：没有记录时从头开始，不继承前一文件的进度。
- 返回已读文件或重开页面：内容哈希一致时恢复该文件自己的进度。
- 同 ID 内容被重新编译：哈希变化后从头开始。
- 从头阅读：清除当前文件已保存位置，不影响其他文件。
- 本机持久存储不可用时仍能阅读；不承诺跨 Mac 同步阅读状态。

App 不设置每日 API 总额度。课件和字幕失败按5／15／45／120分钟退避，连续失败后最多每6小时重试；不因累计3次永久跳过。重启保持冷却和检查点，来源变化重新计数，人工稿保护继续有效。课堂总结使用独立的deepseek-chat及编译请求超时，不随用户聊天模型切换为reasoner。合成测试只验证协议与状态，不冒充真实模型或平台验收。
