# 1.8.9 发布范围与排障依据

此版本沿用本地功能分支，包含已完成的课件自动 Markdown 同步、编译结果浏览、只读 AI 知识点检索及邮箱跨设备诊断修复；不搬运两个旧脏工作树的修改。

## 凭据输入

- `dashboard-web/src/components/ui/SecretInput.tsx` 为四类连接凭据提供浅灰眼睛按钮，默认隐藏，仅切换当前输入框类型。
- 按钮可键盘聚焦，具有显示／隐藏标签、按下状态，不触发表单提交。
- 保存、删除、测试连接等忙碌状态及关闭对话框时重新隐藏；关闭后清空草稿，已保存凭据不回显。
- 回归覆盖四类凭据、取消重开、保存失败及数值保持。

## 更新检查

现场本机能读取官方 1.8.8 Release，并匹配 macOS arm64 资产及 SHA-256。未收到朋友的错误原文或新的诊断包，尚不能确定朋友环境的具体根因。

可验证的旧流程缺口是网络失败统一报错、失败后缺少发布页入口，默认连接／读取超时为 3／5 秒。新版本：

- 分别展示超时、网络、TLS 验证及 HTTP 状态的安全提示；不输出远端正文或底层敏感异常消息。
- 连接／读取超时调整为有界的 10／15 秒，不进行无限重试。
- 在系统信任之上显式加载随包 certifi CA，不使用构建机绝对证书路径，不跳过 TLS 验证。
- 检查失败也能打开固定仓库的官方发布页，重试清除过期结果。
- 更新检查的阶段、异常类型链及 HTTP 数字状态码写入既有脱敏诊断日志，并随诊断包导出。

URL HTTPS 主机与仓库白名单、重定向限制、元数据大小限制及 SHA-256 要求保持不变。不加入第三方镜像，不自动安装，不读取 GitHub 或邮箱凭据，不改变代理策略。

## 真实环境边界

GitHub API 和公开资产链接可进行只读真实验证。HTTP 403／429／404、超时和 TLS 失败由可控传输回归验证，不能描述成朋友电脑的实测结果。Windows CI 打包不等于 Windows 真机运行通过。

若朋友仍失败，请先在 1.8.9 点击一次检查更新，随即导出诊断包并提供错误截图。诊断中的 `source=update`、`stage=release_metadata` 可区分 HTTP 状态及底层错误类型；无需提供密码。

本轮发行准入的 Windows pytest 最终日志（run `43585245270`）为 16 failed、1000 passed、12 skipped、386 subtests，用时 28 分 54 秒。失败集中于三个新知识模块测试文件：默认 CP1252 读写误用于 UTF-8 文档、LF 夹具在 Windows 被转换为 CRLF；长正文断言差异还在 difflib 生成报告时触发 RecursionError。已将测试读写编码显式限定为 UTF-8，偏移夹具显式写 LF，不修改 CI 默认编码、不跳过测试。

同时修正 `compiled_knowledge.py` 标题提取在 CRLF 文档中携带回车的问题；正文、搜索游标与分页维持原始字符语义，不改写用户文档。新增 CRLF 中文标题／Unicode 游标／分页完整性及非法 UTF-8 拒绝且不改写回归。CI 保留逐用例输出、120 秒线程栈和 30 分钟任务上限，后续重新运行七项检查；最终结果以真实 CI 为准。

## 发布与本地部署约束

发布新版本 `v1.8.9`，不重写已有版本或删除历史资产。发行标签指向精确提交，在功能分支执行完整 CI 后由双平台发行流程生成 macOS DMG、Windows 安装器和便携包及各自 SHA-256。主分支不直接推送、不变基、不强推。

本地 App 从同一精确提交独立构建；先验签，正常退出旧 App，创建新的时间戳回退副本后替换，保留所有旧回退。ad-hoc 签名不等于 Developer ID 签名或 Apple 公证。实际提交、验证数量、产物哈希、回退路径与进程由本轮交付记录列出。
