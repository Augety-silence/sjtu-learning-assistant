# SJTU Learning Assistant 1.8.18

本次小版本整合界面修复及此前本地 1.8.14–1.8.17 的编译、断点恢复和字幕同步改进。

（2026-11-22）提示遮挡、邮件溢出与视频切页重载问题

问题：部分信息提示被窗口边界裁掉或被其他元素压住；短邮件窗口过大、长邮件容易溢出；课程视频切页后需要重新加载；透明设置浮层透出背后的文字。

解决：信息提示统一为灰色半透明底、白字，放到全局提示层并贴合窗口边界，支持鼠标悬浮、键盘焦点和 Escape 关闭。邮件按内容自适应高度、整体居中，长正文在有界区域滚动。保留访问过的视频页、播放器与已有缓存；离开页面自动暂停，返回保留播放位置。透明浮层、页头与底部输入区补齐 macOS 所需的模糊样式，浮层增加遮蔽底色；减少透明度模式使用实色。

现状：前端 67 个测试文件、592 项用例通过；Mac 完整 Python 验收 1185 项通过（1 项跳过）。原生 WKWebView 在 1280、760、390 像素宽窗口下验证提示边界、短长邮件居中与滚动；设置浮层模糊及同一播放器切页复用通过。保留账号、资料、字幕、总结断点与阅读记忆，不清理已有通过稿。真实 Canvas 网络直播的连续缓冲表现仍受服务端和网络影响，不承诺跨 App 重启缓存视频。

（2026-11-22）精炼失败与重复消耗 Token 问题

问题：新资料精炼效率低，重试可能重复读取已经处理过的内容；原始字幕只在打开录像后同步。

解决：课程总结正文放宽到 5000 字，按资料规模精炼；保留阶段检查点、成功响应与已完成稿，重试从缺失阶段继续。外部链接、宏和嵌入对象保留来源，不执行、不打开。课件和字幕分别使用 6／4 个工作线程，共享每分钟最多 10 次请求、300000 Token；不设置每日调用上限。字幕支持提前全量同步，播放字幕与时间轴同步。

现状：本版本一起发布此前的本地 1.8.14–1.8.17 改进。并发上限不是速度承诺，实际完成速度仍取决于学校服务响应、限流与源资料可用性。

## 发布说明

Mac 本机已安全替换到 1.8.18，签名与包结构验证通过。替换前暂停新 AI 请求并等在途请求归零，保留旧 App 备份，替换后恢复后台自动编译；未删除学习资料或已完成检查点。

macOS 使用与现有版本一致的 ad-hoc 签名，未 Apple Developer ID 签名或公证；Windows 由 GitHub Actions 构建，云端测试不代表 Windows 真机界面验收。界面验收使用合成邮件和本地视频，不读取学习库、不调用付费模型。不会宣称所有历史课程资料已经重新编译。
