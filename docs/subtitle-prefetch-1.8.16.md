# 全课程字幕预同步与播放器修复（1.8.16 本地版）

问题：此前只有打开过的录像会保存字幕，后台仅处理这些已有记录；动态加载的字幕轨道在 Mac 播放器中也没有可靠显示。

解决：启动后自动扫描本地已导入的所有课程，包括往期课程。视频页提供“同步全部字幕”，无需逐个点开录像。原始字幕独立下载并生成可读 Markdown，不等待 AI 校对；已保存字幕优先从本地读取。字幕下载队列保存在本地，支持重启续传、延迟重试与缓存复用。远端仍在生成或没有权限的字幕不冒充完成。

播放：字幕叠加在视频画面内，使用播放器实际时间；跳转、暂停、倍速不会另起计时。内嵌及工作台全屏用叠加字幕，原生视频全屏启用字幕轨道，避免重复显示。左上角小字幕按钮可切换显示，不占用退出全屏按钮。

保护：不重置课程库，不覆盖已有课程总结或人工稿，不改变原始字幕时间戳；原始字幕下载不使用模型。模型总结继续走原来的独立队列及限速。

验证：

- 前端全量 589 项通过，格式检查与生产构建通过。
- 后端全量 1234 项及 503 个子测试通过、3 项跳过；首次测试发现沙盒代理配置问题，清除该测试进程的代理排除项后复验通过，不修改用户网络设置。
- 新增覆盖未打开录像、101 堂分批、网络/生成中重试、重启续传、缓存损坏、人工稿保护、历史课程与权限隔离。
- Mac 真实课程验收：此前未打开的一堂录像保存 76 条字幕，零模型调用，原有字幕未修改。
- WKWebView 真实录像验证：字幕显示、两次跳转匹配、2 倍速播放、1050/760 两种窗口宽度与字幕开关通过。

现状：1.8.16 已完成本机构建、代码签名与安装，旧 App 已移到项目 `backups/subtitle-1.8.16-20261122` 保留回退。替换后真实后台已发现 419 个需要下载的字幕任务，其中 53 个完成，原始字幕缓存由 22 堂增长到 75 堂；75 份原文与关联 MD 均可通过读取入口访问，读取失败为零。课程扫描与下载仍在继续，不能把“已入队”当作“全部完成”。

GitHub 未推送、未发布。本次没有进行 Windows 实机或逐堂人工听音验收；远端原字幕识别错误及其时间戳误差不在上述播放时间轴验证的保证范围内。原字幕时间戳不被猜测性偏移。
