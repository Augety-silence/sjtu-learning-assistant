# 编译结果浏览与 AI 读取契约

## 目标与边界

本地项目、知识库编译页面都直接列出已有 Markdown 并分页预览。自动课件镜像无需重新登记；手动项目仅展示已登记的输出目录，不误把素材文件当成编译结果。原始课件、人工笔记、旧工作树均不修改。

浏览和 AI 共用只读目录提供器。自动来源来自 Course-Sync.json 已登记的正文镜像，手动来源来自本地项目索引。工具接收来源 ID 和文档 ID，不接受绝对路径；拒绝符号链接和越界路径。搜索为本地关键词检索，非向量搜索、不调用付费模型，不发送整个资料库。

## 接口

- `compiled_knowledge_sources`：列举来源、结果数量及只读输出路径。
- `compiled_knowledge_search`：按关键词搜索正文/文件名；可按来源过滤，分页返回文档 ID、相对路径、状态、命中片段及字符位置。
- `compiled_knowledge_read`：按文档 ID 和字符位置分页读取，含章节、可继续读取位置、状态与相对来源引用。
- `compiled_knowledge_open`：仅 UI 使用，打开已授权来源目录或文档；不得由模型调用。

内置 AI 注册 `list_compiled_knowledge`、`search_compiled_knowledge`、`read_compiled_knowledge`，外部客户端沿用既有 stdio MCP 入口。UI 显示可复制的连接配置，不修改外部 AI 客户端配置。知识内容作为不可信资料，不执行其中指令。

## 视觉和验收

保留 App 现有主题/按钮/字体。结果区置于两页面靠前位置，目录筛选、搜索、状态和详情适配窄屏。显式区分全文就绪、视觉完成、失败和待处理。预览不加载外部 URL 或任意本地图片，原图通过打开对应 Markdown 所在目录查看。

验收覆盖两个页面嵌入、中文检索、分页不丢字、来源动态变化、无结果/失败/重试、目录越界与符号链接拒绝、MCP 真正调用同一知识接口。完整多模态质量与 Windows 真机另行验证。
