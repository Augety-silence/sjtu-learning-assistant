# SJTU Learning Assistant 即时补充与并行会话修复

本轮修复第二条输入等待当前回复结束、执行中无法新建对话的行为。同会话补充即时调整原任务，不重置预算或重新读取已取得的证据；新对话具有独立任务、进度和停止控制器。

Mac 基线为 `09d14d09b6a46ecda83ba8042bf09b892a682e21`，沿用现有工作分支。部署版本保持 1.8.18。本目录保存源代码、精确补丁、测试、独立部署与保护验收脚本以及接续记录。最终提交、原生验收和部署结果在 `PROGRESS.md` 与 `TEST_REPORT.md` 中记录。

补充消息先持久化，使用原请求标识重试；任务结束后未接收的输入恢复为草稿。已接收但遇到执行上限的补充明确说明未完成。每任务最多 12 条补充，原模型调用数、token 和总时长预算保留。文本附件可即时补充；图片补充请在新对话中发送。

工程验证包含本地 HTTP 无首 token 中断、共享客户端隔离、共享预约取消、部分付费响应与用量保存、正文证据复用、收尾竞争、A/B 并行与草稿隔离。测试使用模拟资料，性能数字不代表真实模型响应时间。

知识库继续保留既有原件、人工稿、已完成稿、付费响应及检查点。没有清库、全库重编或重置重试次数。近期知识库恢复已新增 3 份课件、6 份课堂总结；本轮聊天窗口修复期间新增完成稿为 0。具体残留失败按最终只读观察记录。

本轮仅本地提交和可回退部署，不推送 GitHub、不合并远程分支、不发布 Release。长期记忆系统继续按后续阶段推进，不能将这次聊天修复视为完整记忆系统交付。

## 中断专项

14 个用例涵盖等待响应头、等待首 token、流式与非流式中断、共享客户端 A/B 隔离、中断片段与实际用量、完整响应收尾竞争、共享限流排队取消、有界终止、连续补充上下文容量。21 个服务用例涵盖提前持久化、请求幂等、消息序号、终态拒绝、停止优先、附件范围和真实 AgentLoop 服务闭环。

本地 HTTP 实验在中断信号后 1.5 秒内结束阻塞请求，B 会话在 A 阻塞期间和中断后均成功。该结果仅用于验证中断机制，不代表远端模型端到端延迟。测试没有调用付费模型。
