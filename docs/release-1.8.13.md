# SJTU Learning Assistant 1.8.13

本补丁版本发布 v1.8.12 后已完成的本地迭代，保留旧 Release、学习资料、设置及阅读记忆。

## 本次更新

- 知识库按原学期、课程及课时统一收纳课件与课堂字幕，修复重复目录和同目录文件展示不全；没有课程身份的文件不靠名称猜测归属。
- AI 可检索课程 Wiki、读取对应 Markdown 正文，并按需核验原始课件页；读取预算不足会明确说明，不将文件名查询冒充正文检索。
- 课堂资料呈现为原始字幕与精炼当堂总结，关联课程并进入只读知识检索；修复已有字幕无法生成课堂 Markdown 的问题。
- 扩大阅读空间，按文档独立保存阅读位置；从头阅读操作随工具栏保留，正文支持自由选择复制。
- 课堂视频采用静默自动同步，保留小型重试入口和断点续同步；完善课件 PDF 缓存和遮挡修复，清除无关进度展示及冗余组件。
- macOS 关闭窗口后继续后台同步，保留显式退出；设置新增输入、输出、缓存及总 Token 仪表盘。服务未返回 usage 时标记未报告，不虚构消耗。
- 精简常驻说明、次要标签和重复微文案；必要补充使用鼠标悬浮或键盘焦点提示，保留表单标签、读屏名称、错误与危险操作后果。
- 课程知识库导航上移，资料项目放在最后；桌面与移动导航保持一致。

## 发布与验证边界

本机 macOS 完整 unittest 执行 1133 项，结果通过（1 跳过）；完整 pytest 1207 通过、1 跳过、499 子测试通过。前端 Vitest 64 文件／580 用例通过，Biome 检查 170 文件、TypeScript 与 Vite 生产构建、compileall、Python/npm 许可证和 diff 检查通过。秘密模式扫描通过，但 7 个非 UTF-8 文件未做文本扫描；GitHub gitleaks 单独进行全历史扫描。jsdom 媒体未实现、Vite 主 chunk 超过 500 kB 与 macOS 多线程 fork 警告仍为非阻断信息。

发布前执行完整 Python unittest／pytest、前端 Vitest、Biome、类型检查与生产构建，以及 compileall、许可证、秘密模式和 diff 检查；GitHub 七项 CI 全部通过后才推送正式版本标签。精确提交的 macOS／Windows 发布构建成功后，由发布流程上传安装包及 SHA-256 文件并标记 Latest。

macOS 使用 ad-hoc 签名，未 Apple Developer ID 签名或公证；Windows 未提供商业代码签名。Windows runner 的测试与打包不等于 Windows 真机界面、原生拖拽或网络盘验收。既有原生 Mac 多尺寸验收使用合成资料，不宣称全库真实课程内容都已重编或人工验收。

本次不调用模型测试、不写真实学习资料、不重置账号或数据库，不删除旧 Release 或回退。每日 App 总调用额度仍为 0（不设置上限），学校限速、取消和有限重试继续有效。
