# SJTU Learning Assistant 1.8.10

本补丁版修复邮件内嵌图片无法显示，并包含此前只在本地修复构建中提供的更新检查回退与邮件布局兼容修复。

## 邮件图片

- 修复真实邮件内嵌 PNG 被声明为 `application/octet-stream` 时被拒绝显示的问题。只对当前用户安全附件目录内、属于这封邮件、有 Content-ID 的内嵌附件，按文件头识别 PNG/JPEG/GIF/WebP；不依赖文件名，不放开 HTML/SVG，不改变大小和路径限制。
- 已缓存图片直接本地显示，不需要重新下载邮件或登录其他服务。缺少直接预览数据时，可通过所属邮件的受控资源读取接口重试。
- 区分资源元数据缺失、读取失败与图片解码失败提示。前端不展示原始异常、附件路径或 URL。
- 诊断包补充 `source=mail_image` 的内嵌缓存读取、类型恢复、远程读取阶段和异常类型/HTTP 数值状态。固定枚举说明失败类型；不记录正文、邮件标识、CID、图片内容、文件路径、URL、账号或凭据。

## 一并提供的兼容修复

- GitHub API 返回 403/429 时，可回退核验 GitHub 官方 Latest 发布页；不会使用第三方代理或开发者 token，也不会从网页猜测安装包及 SHA-256。
- 邮件布局表格去掉不属于原邮件的网格外框，保留有限对齐/尺寸属性和正常数据表语义。
- 已支持的交大公开外部图片仍需用户明确同意，匿名读取、逐跳限制来源；切换邮件不会沿用授权。

## 验证边界

截图对应邮件的缓存只读核验已确认：PNG 文件存在，大小 34,215 字节，声明为通用 MIME，位于当前附件目录。修复前没有可用 inline data，修复后应返回 PNG data URL；不改写真实邮件或附件。

Windows 自动构建与 CI 不等于朋友电脑的真实运行验收。朋友请升级 1.8.10 后复测；仍有问题可打开该邮件、重试一次，随后导出诊断包，无需提供密码或完整邮件。

发布使用新 tag `v1.8.10`，不覆盖或删除任何历史 Release/资产。
