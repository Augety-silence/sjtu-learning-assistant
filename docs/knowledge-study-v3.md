# 完整课程讲义与稳定浏览（2026-11-20）

当前默认契约为 `course-study-v3`。本轮依据用户录屏与完整对话附件落地；历史 v2 验收记录保留，不代表本轮全部已重编。

## 讲义生成与保护

每原件仍对应一份 MD：`Knowledge Markdown/Courses/学期/课程/分类/原文件名.pdf.md`（PPTX 同理）。原文件夹层级不变。

全部页面先做主题规划，再按知识依赖重组章节，输入完整原文和视觉证据，最后核对符号、条件、推导、页码和教学补充；审校发现问题先定向重写一次。结构、来源或审校失败保留检查点和旧稿，不发布残缺终稿。此审校是模型来源核对，不是数学形式证明或教师认证。

正文包含学习目标和建议顺序、主题讲解、定义／模型／条件／推导／直觉／易错点、一页提纲、4–6 道教学补充自测、具体待核对清单和文末答案。原课件结论引用 `[课件 p.N]`；补写证明和例子明确标记。正文数字不能覆盖权威页码字段。图表或条件缺失不猜造原题。

逐页证据、原图、原文与旧版本保留于 `90_Inbox/Documents`，正文只回链，不重复堆积。已注册且哈希未变的 v2 视觉页可直接复用，升级只重组讲义；人工编辑的稿件不覆盖。默认自学讲义已实现；难度／考试／练习预设和指定章节重写入口未在本轮新增。

封面／纯目录、纯标题过渡页、纯致谢结束页以 `context_pages` 明确登记并由来源审校确认，不捏造知识点。有总结要点的页仍须实质讲解与引用，不能借此排除。组合引用和要点／缺失项明确写出的“第 N 页”仅做格式规范化；正文的编号不用于推测来源。历史格式失败响应可重新校验并恢复为草稿，但不能跳过来源审校。

整章格式重写仍遗漏实质页时，使用这些页的完整原文／视觉证据定向补齐，再对合并整章来源审校；不会仅附 citation 凑覆盖。补齐检查点可续用，不重复已完成章节；旧补齐稿也须按当前校验恢复，最多两次结构尝试，不允许递归补齐，失败明确报告关联页码。

若定向重写后仍存在来源矛盾，自动把审校明确指出的本批次页图交给 Qwen 重新复核，再重写和审校整章。仅复核关联页，原始图和历史视觉转写不覆盖；新证据独立保存并从主讲义回链。审校缓存和重写缓存有独立版本／问题标识，不能用旧不通过结论卡住修正，也不能用旧结论跳过新核验。

纠错重写明确使用新证据核实每条意见，旧失败稿仅作对照，不能原样复写；审校意见不自动视为事实。原图复核后仍有问题时，仅再允许一次定向修订并完整审校，仍不通过则停止该文件并保留旧稿，不无限循环。纠错缓存身份包含证据、草稿、问题和纠错约束，避免重复读取已失败版本。

Markdown 表格的表头、分隔行和数据行列数由程序核验，错列稿不能只靠模型审校“通过”后发布；已缓存草稿被新增校验拒绝时保留错误续改。原图复核已经确认的内容不得继续把 OCR 错误记作课件缺失，补写证明的向量约定和非负条件也须核对。

同一页已有注册且哈希核验通过的新原图复核证据时，后续编写优先复用该证据。错列表格的旧数值不重新放入纠错提示；原图复核后的重写只保留旧主题标题，直接根据完整证据重新撰写。审校缓存身份包含完整证据和草稿，证据或正文变化即重新核验；通过的修订稿提升为章节检查点，续跑不重复已完成调用。

知识总结页被模型误列为非知识范围时，错误明确关联页码并从完整证据重写，不因没有例题／公式而排除知识提纲，也不重灌旧失败正文。纯致谢页仍可登记，合并稿必须重新审校。

完整章节允许最多24条复习要点，不通过截断正文凑8条；文本字段失败明确报告字段名、数组数量和单条长度限制。涉及线性规划时，补充统一向量约定、对偶非负剩余量、检验数符号与零影子价格的单向蕴含约束；审查意见也须核实，不能因模型要求而反改正确公式。

撰写由 DeepSeek 完成，来源与数学审校使用独立 Qwen 模型；审校模型、完整证据与正文参与缓存身份。提纲／自测缓存绑定已审校要点，章节修订后不会复用旧下游内容。自测不通过时最多一次整组纠错并重新审校，题设必须成立、答案完整，成功才保存可零调用续用的检查点。当前本机密钥的 `/models` 列表未包含 MiniMax，两个 MiniMax 别名均返回权限错误，不能把批准邮件视为每个别名均已实际可用。

## 阅读、复制和 AI 检索

目录请求和正文读取期间保留旧内容，不卸载目录树；过时请求不能覆盖新选择。正常大小（不超过 24 万字符）的新版本 MD 自动读完整后展示。更长文档采用追加分页，明确这是阅读分页而非编译截断；“复制完整 Markdown”始终从头取全文并检查哈希、偏移与总长度，版本变化则拒绝混合复制。数学使用 KaTeX，禁用可信命令、外部图片、HTML 脚本和外部链接执行。

课程镜像含来源、摘要、主题和同义词。App 和现有只读 stdio MCP 搜索／读取同一份文件，可直接提供给本机 AI 工具；不是新向量数据库，不宣称已新增语义向量 RAG。

## 调用规则

自动同步与 App 手动多模态编译不设每日或每次总调用额度。旧每日设置字段仅兼容读取，状态 `daily_limit=0` 表示不限；保留统计。学校服务端的 RPM、TPM、每周额度仍有效，客户端保留全局六秒请求间隔；不是无限并发。

每个坏文件每天最多自动尝试三次、每请求有限网络重试；这是避免坏文件循环，不是 API 日总额度。暂停／取消仍有效。独立命令行仍默认保留 100 次进程预算（可通过 `--max-calls` 调整），安全文件／页数／大小上限仍保留。

知识编译采用独立的 16 万字符单消息／18 万字符总上下文预算，章节输入仍分批且有界，不截断证据。普通聊天的 14,000／60,000 字符限制、工具限制和图片校验保持不变；扩展模式不允许工具或聊天历史，避免编译审校被聊天预览限制误拦。

本轮不 push、PR、远端合并、改版本或 Release。精确提交、本机真实 API 结果、全部验证与 App 部署信息见同一交付目录的验收记录；模拟测试不代表真实课程或 Windows 真机验收。
